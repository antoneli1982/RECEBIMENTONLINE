# RECEBIMENTONLINE

SISTEMA DE RECEBIMENTO DE VEÍCULOS DA SESE.

## CONTEÚDO

O PROJETO CONTÉM O SISTEMA WEB, A INTEGRAÇÃO COM FIREBASE, O PROJETO ANDROID E O PROJETO IOS.

O ARQUIVO PRINCIPAL DO SISTEMA É `index.html`.

A PASTA `mobile-web` É A FONTE UTILIZADA PELO FIREBASE HOSTING E PELOS APLICATIVOS.

A PASTA `android` DEVE SER ABERTA NO ANDROID STUDIO.

A PASTA `ios` DEVE SER ABERTA NO XCODE EM UM COMPUTADOR MAC.

## FIREBASE

O PROJETO FIREBASE CONFIGURADO É `recebimentonline-30fe7`.

OS REGISTROS SÃO SALVOS NA COLEÇÃO `recebimentos` DO FIRESTORE.

O FIREBASE HOSTING PUBLICA O CONTEÚDO DA PASTA `mobile-web`.

## INSTALAÇÃO

INSTALE O NODE.JS EM VERSÃO COMPATÍVEL COM O PROJETO.

NO TERMINAL, ENTRE NA PASTA DO PROJETO E EXECUTE:

```bash
npm install
```

PARA ATUALIZAR OS PROJETOS ANDROID E IOS, EXECUTE:

```bash
npm run mobile:sync
```

## PUBLICAÇÃO NO FIREBASE

FAÇA LOGIN NO FIREBASE:

```bash
firebase login
```

PUBLIQUE O SISTEMA:

```bash
firebase deploy
```
